# Brightness

Adjusts how light or dark an image appears by adding or subtracting a constant value from each pixel’s color channels.

$C_{out} = C_{in} + b$

Where:

- $C_{in}$ = input color
- $C_{out}$ = output color
- $b$ = brightness amount

Expanded per channel:

$$\begin{aligned}R' &= R + b \\ G' &= G + b \\ B' &= B + b\end{aligned}$$
